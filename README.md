##  Description

Mini Game Hub is a fun and interactive web application built using HTML, CSS, and JavaScript. It includes games like Tic Tac Toe and Rock Paper Scissors with smooth UI and real-time gameplay. This project showcases strong JavaScript logic, DOM manipulation, and creativity.



##  Features

 Tic Tac Toe Game
 Rock Paper Scissors
 Interactive UI
 Fast & Responsive Design
 Beginner Friendly Code



##  Games Included
